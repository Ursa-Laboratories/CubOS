# Step-execution view screenshots

Generated by the E2E suite, not hand-captured:

```bash
cd apps/operator-web && npx playwright test tests/e2e/run-steps.spec.ts
```

Each image is the real `RunPanel` rendered by the real app against the
hermetic API mock in `tests/e2e/apiMocks.ts` (no backend, no hardware). The
scenarios live in `tests/e2e/run-steps.spec.ts`.

| File | Scenario |
| ---- | -------- |
| `run-steps-liquid-handling.png` | A run mid-transfer, with compound-command substeps nested under their step. |
| `run-steps-resumed.png` | A resumed run: steps the fluid journal reports as already applied are marked skipped, with the reason spelled out. |
| `run-steps-failed.png` | A failed run: the failing step is named with its error; steps that were never reached stay pending. |

Regenerate them whenever the panel's layout or status vocabulary changes.
