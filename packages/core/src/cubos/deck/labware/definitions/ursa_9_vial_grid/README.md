# Ursa 9-vial grid

Flat calibrated layout for the Ursa tight-fit 20 mL vial holder. Use
`load_name: ursa_9_vial_grid` in deck YAML and supply measured `calibration.a1`
and `calibration.a2` coordinates. A1/A2 are adjacent vial-rim centers; their Z
is the pipetting reference surface.

The nominal center pitch is 33.0 mm. Override the offsets only when a measured
holder differs from this definition.
